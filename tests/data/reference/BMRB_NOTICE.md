# BMRB data in ARISE's tests

`bmrb_cases.tsv` and `bmrb_peaks.tsv` contain data from the Biological Magnetic Resonance Data Bank (BMRB, https://bmrb.io), metabolomics entries, read through BMRB's public API by `scripts/build_bmrb_reference.py`. The data are used only to test ARISE and are not part of the ARISE engine.

BMRB publishes no formal licence. Its own statements, quoted from its pages on 2026-11-05 (generated by the builder, which stops if a page no longer says this):

> BMRB collects, annotates, archives, and disseminates (worldwide in the public domain) the important spectral and quantitative data derived from NMR spectroscopic investigations of biologically relevant molecules.
>
> — BMRB Mission Statement, https://bmrb.io/bmrb/mission_statement.shtml

> The data are supplied by the NMR community and are made publicly available free of charge.
>
> — BMRB Metabolomics standards data policy, https://bmrb.io/metabolomics/data_policy.shtml

> Users are requested to acknowledge BMRB in publications: a sample acknowledgment is available from the BMRB web site .
>
> — BMRB Aims and Policies, https://bmrb.io/bmrb/aims_and_policies.shtml

> All exported data have the author(s)' name(s) attached to the entry and list the primary publication associated with the BMRB file.
>
> — BMRB Aims and Policies, https://bmrb.io/bmrb/aims_and_policies.shtml
